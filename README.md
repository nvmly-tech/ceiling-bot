# ceiling-bot

Telegram-бот первичного контакта для студии натяжных потолков: 4 вопроса → заявка → карточка в Trello.
Переписка и анкета хранятся в SQLite. Этапы 3–6 добавят уведомления менеджеру,
расшифровку голосовых, LLM и деплой под systemd.

## Trello

Карточка создаётся на первом сообщении клиента в списке `TRELLO_LIST_NEW`. Анкета — в описании
(обновляется по мере ответов), каждое сообщение переписки — отдельный комментарий, под ответами бота
подписана модель. Метки «квалифицирован» / «не завершил анкету» / «ночной» бот создаёт сам;
метки, поставленные менеджером вручную, не трогает.

Все вызовы Trello идут через очередь `outbox` в SQLite: если Trello недоступен, задачи повторяются
(5 с, 10 с, 20 с … до 30 мин), порядок сообщений внутри лида сохраняется, лид не теряется.

## Локальный запуск

```bash
cp .env.example .env   # вписать BOT_TOKEN тестового бота от @BotFather
uv sync
uv run python -m app.main
```

## Тесты

```bash
uv run pytest
uvx ruff check app tests
```

## Структура

- `app/bot/handlers.py` — диалог; `texts.py` — все тексты; `keyboards.py`, `states.py`
- `app/bot/storage.py` — FSM в SQLite (переживает рестарт)
- `app/db.py` — лиды, переписка, outbox, FSM
- `app/services/trello.py` — клиент Trello, оформление карточки, синхронизация
- `app/services/outbox.py` — воркер очереди с ретраями
- `app/parsing.py` — площадь и телефон из свободного текста
- `app/worktime.py` — рабочие часы и ночной режим
